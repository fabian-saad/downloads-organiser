# Downloads Organiser

A simple Go script that automatically cleans up the Downloads folder by organising files into categorised subfolders based on their extension.

## Prerequisites

Go 1.21 or newer

## Usage

Clone or download the repository.

```bash
git clone https://github.com/fabian-saad/downloads-organiser.git
cd downloads-organiser
```

Run the script in your terminal:

```bash
go run main.go
```

Or build an executable:
```bash
go build -o downloads-organiser.exe
```
